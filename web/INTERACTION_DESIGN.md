## 3. 聊天交互

### 3.1 消息气泡

```
用户消息 (右对齐):                    AI 消息 (左对齐):

         ┌──────────────────┐     ┌──────────────────────┐
         │                   │     │                       │
         │ 买了3卷Portra 400 │     │ 好的，已记录 📝         │
         │                   │     │                       │
         │       10:32  📋  │     │ 📦 **当前库存**:         │
         └──────────────────┘     │ Portra 400 × 8卷      │
                                  │                       │
                                  │  ⚠️ 有 2 卷快过期了     │
                                  │              10:32 📋 │
                                  └──────────────────────┘
```

**消息操作** (hover / long press 显示):
- 📋 复制
- ↩️ 引用这条 (后续支持)

### 3.2 流式聊天流程

```
[用户输入] → 发送
    ↓
1. 用户消息立即显示 (本地渲染, 无网络等待)
2. 输入框清空, 占位变为 "正在回复..."
3. AI 回复区域出现 + 光标闪烁
4. 逐 token 流式显示 (打字机效果)
   ├── 如有工具调用: 在 AI 消息上方显示工具指示条
   │   ┌─ 🔍 查询库存... ────────┐
   │   └────────────────────────┘
   └── 工具完成 → 指示条消失 → AI 继续输出
5. 回复完成 → 完整显示
```

### 3.3 输入框

```
┌──────────────────────────────┐
│ 记录胶卷、查库存、问问题...  🚀 │
└──────────────────────────────┘
```

- **Enter**: 发送
- **Shift+Enter**: 换行
- **auto-resize**: 最多 6 行，超出滚动
- **发送中**: 按钮 loading 态，输入框禁用
- **空输入**: 发送按钮禁用 (opacity 0.4)

### 3.4 欢迎页

```
      🎞️

  欢迎使用胶片伴侣

  你的 AI 胶片管理助手。
  说人话就能管好胶卷和设备。

  [📸 录入胶卷] [🔍 查库存]
  [⚠️ 过期提醒] [📷 查设备]
```

### 3.5 会话标题

- 第一条用户消息自动截取前 48 字作为标题
- 顶栏显示当前会话标题
- 侧栏列表显示标题 + 最后一条消息预览

## 6. 登录注册

### 6.1 登录弹窗

```
┌─────────────────────────┐
│                         │
│     🎞️                  │
│    胶片伴侣 AI            │
│                         │
│     👤 用户名             │
│    [________________]   │
│     🔒 密码              │
│    [________________]   │
│                         │
│    [      登  录      ] │
│                         │
│    ───────────────       │
│    还没有账号？立即注册   │
│                         │
└─────────────────────────┘
```

- 背景半透明模糊
- 打开自动聚焦用户名输入框
- Enter 键提交
- 登录/注册共享位置，切换时表单 fade + slide 过渡

### 6.2 注册

- 比登录多一个"确认密码"字段
- 验证：用户名 2-32 字符、密码 ≥6 位、两次一致
- 注册成功 → 自动登录（免去再输一遍）

### 6.3 登出

点击顶栏用户名 → 下拉菜单中 "退出登录"
或点击 "退出" 按钮

### 6.4 Token 无感刷新

```
[页面加载] → 检查 access_token
  → 有效 → 正常使用
  → 过期 → 自动用 refresh_token 换取新 access_token
    → 成功 → 继续
    → 失败 (refresh 也过期 / 单点登录被踢)
      → 弹出登录框, 提示原因
```

## 7. 动效规范

| 场景 | 动效 | 时长 | 缓动 |
|------|------|------|------|
| 页面切换 | fade | 200ms | ease |
| 登录弹窗 | fade + scale | 300ms | ease-out |
| 侧栏展开 | slide from left | 250ms | ease-out |
| 消息出现 | fadeIn + slideUp | 200ms | ease-out |
| 流式 token | 打字机 | ~150ms/字 | linear |
| 工具指示 | fadeIn | 150ms | ease-out |
| 统计数字 | count-up | 600ms | ease-out |
| Tab 切换 | slide underline | 200ms | ease-in-out |
| Hover | 背景变亮 | 150ms | ease |
| 点击反馈 | scale(0.97) | 100ms | ease |
| Toast | slideDown + fade | 300ms + 停留3s | ease |

## 8. 响应式

| 断点 | 设备 | 行为 |
|------|------|------|
| <480px | 手机竖屏 | 全宽布局，侧栏全屏滑出，消息 92% 宽度 |
| 480-768px | 手机横屏/小平板 | 侧栏 280px 滑出，消息 88% |
| 768-1024px | 平板 | 侧栏可固定，主区域自适应 |
| >1024px | 桌面 | 完整布局，侧栏 overlay |

### 移动端专项

```
底部安全区:     env(safe-area-inset-bottom)
键盘适配:       输入框跟随键盘, 不遮挡
点击区域:       ≥44px (Apple HIG)
侧栏手势:       左边缘右滑打开
消息操作:       长按弹出操作菜单
防 iOS 缩放:    input font-size: 16px
```
