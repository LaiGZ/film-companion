# 交互设计规范 v2 — 胶片伴侣 AI

> 交互参考: 豆包 · DeepSeek · ChatGPT · Claude
> 核心思路: **像用 AI 聊天一样管理胶片，而不是像用 ERP 一样**

---

## 1. 整体风格

```
┌────────────────────────────────────────────────┐
│                                                  │
│   🎞️ 胶片伴侣 AI           [主题切换 ▼]  📊    │  ← 极简顶栏
│                                                  │
├──────────────────────────────────────────────────┤
│                                                  │
│              ┌──────────────────────┐             │
│              │  买了3卷Portra 400   │             │  ← 用户消息右对齐
│              └──────────────────────┘             │
│                                                  │
│   ┌────────────────────────────┐                  │
│   │ 好的，已记录 📝             │                  │  ← AI 消息左对齐
│   │ 当前库存：                  │                  │     居中 max-width
│   │ Portra 400 × 5卷           │                  │
│   └────────────────────────────┘                  │
│                                                  │
│              ┌──────────────────────┐             │
│              │ 有哪些反转片？        │             │
│              └──────────────────────┘             │
│                                                  │
│   ┌────────────────────────────┐                  │
│   │ 🎞️ 富士 Provia 100F × 3   │                  │
│   │ 柯达 E100      × 2        │                  │
│   └────────────────────────────┘                  │
│                                                  │
│  ┌──────────────────────────────────────────┐    │
│  │  记录胶卷、查库存、问问题...           🚀 │    │  ← 底部固定输入
│  └──────────────────────────────────────────┘    │
│                                                  │
└──────────────────────────────────────────────────┘
```

**关键差异**（对比 v1）:

| 维度 | v1 (暗房) | v2 (AI Chat 风格) |
|------|-----------|-------------------|
| 布局 | 侧栏固定, 传统 IM | 全屏聊天, 侧栏隐藏/弹出 |
| 消息区 | 气泡占 72% | 居中 max-width, 大面积留白 |
| 输入框 | 带图标按钮 | 极简, 聚焦内容 |
| 颜色 | 暗房暖调 (棕色/金色) | 可切换主题, 默认干净中性 |
| 装饰 | 底片齿孔边框 | 去装饰, 内容优先 |
| 侧栏 | 常驻左侧 | 左上角按钮弹出 (如 ChatGPT) |

## 4. 核心交互流程

### 4.1 登录 → 聊天

```
[打开页面]
    ↓
[无 token] → 居中显示登录弹窗
  ┌─────────────────────────┐
  │                         │
  │     🎞️                  │
  │    胶片伴侣 AI            │
  │                         │
  │     👤 用户名             │
  │    [______________]     │
  │     🔒 密码              │
  │    [______________]     │
  │                         │
  │    [    登录 / 注册   ] │
  │                         │
  │    ─── 其他方式 ───      │
  │    还没有账号？立即注册   │
  │                         │
  └─────────────────────────┘
  (背景半透明模糊, 类似 ChatGPT 登录)

[登录成功]
    ↓
弹窗关闭 → 直接进入聊天界面
    ↓
"欢迎回来，demo" toast (2s 自动消失)
```

### 4.2 聊天交互 (参考 DeepSeek/豆包)

```
[用户输入] → 发送
    ↓
1. 用户消息立即显示 (本地渲染, 无网络等待)
2. 输入框清空 + 占位文字变为 "正在回复..."
3. AI 回复区域出现 + 光标闪烁
4. 逐 token 流式显示 (打字机效果)
5. 如果是工具调用: 在 AI 消息上方显示小巧的工具指示条
   ┌─────────────────────────┐
   │ 🔍 正在查询库存...        │  ← 淡灰色, 小字, 不显眼
   └─────────────────────────┘
6. 工具完成后: 指示条消失, AI 继续输出
7. 回复完成后: 完整显示, 支持复制

[多轮对话]
    ↓
上下文连贯, 自动滚动到底
顶部悬浮显示当前会话标题
```

### 4.3 工具调用指示 (参考 Claude Artifacts / DeepSeek)

```
AI 回复中:
  ┌──────────────────────────────┐
  │  我来查一下库存...             │
  │                              │
  │  ┌─ 🔍 查询胶卷 ──────────┐  │
  │  │  正在检索你的库存...     │  │  ← 简洁小卡片, 自动消失
  │  └────────────────────────┘  │
  │                              │
  │  查到以下信息:                │
  │  富士 Provia 100F × 3卷     │
  │  柯达 E100        × 2卷     │
  └──────────────────────────────┘
```

**和 ChatGPT 的关键区别**: 我们不隐藏工具调用, 用极简方式展示（让用户知道 AI 在做什么, 但不干扰阅读流）.

## 5. 消息交互

### 5.1 消息操作 (hover 出现)

```
桌面端: hover 显示
                    ┌────────────────────┐
                    │ 买了3卷Portra 400  │
                    │                    │
                    │      10:32 📋 ↩️  │  ← 复制 / 引用
                    └────────────────────┘

移动端: long press 弹出操作菜单
  ┌────────────────────┐
  │ 买了3卷Portra 400  │
  │                    │
  │      10:32         │
  └────────────────────┘
         ↓ long press
  ┌──────────────┐
  │ 📋 复制       │
  │ ↩️ 引用这条   │
  │ 🗑️ 删除       │
  └──────────────┘
```

### 5.2 消息连续分组

```
同一角色连续消息合并 (无头像/时间重复):

  ┌──────────────────────┐
  │  买了3卷Portra 400   │  ← 用户消息
  └──────────────────────┘
  ┌──────────────────────┐
  │  还有2卷Tri-X        │  ← 合并到同一组
  └──────────────────────┘

  ┌──────────────────────────┐
  │  好的, 已记录 ✅           │  ← AI 回复
  │  目前库存:                │
  │  Portra 400 × 8卷        │
  └──────────────────────────┘
```

### 5.3 加载 & 滚动

```
历史消息加载:
  向上滚动 → 顶部出现 "加载更多..."
  点击或继续上滚 → 加载更早消息
  加载中显示 shimmer 占位

新消息到达:
  如果在底部 → 自动滚动 (smooth)
  如果不在底部 → 显示 "⬇ 2 条新消息" 按钮
  点击按钮 → 滚动到底

输入框:
  Enter 发送, Shift+Enter 换行
  发送后自动清空, 保持 focus
```

## 6. 数据页面交互

### 6.1 入口

```
顶栏: [🎨] [📊]
                    ↑ 点击切换到数据页面

数据页面是独立路由 (/data)
保留聊天页状态, 切换回来时 context 不丢失
```

### 6.2 数据页面布局

```
┌────────────────────────────────────┐
│ ← 返回聊天       胶片伴侣 AI      │  ← 顶栏, 左侧返回
├────────────────────────────────────┤
│                                    │
│  [🎞️ 胶卷]  [📷 设备]  [📸 拍摄]  │  ← tab, 下划线滑动切换
│                                    │
│  ┌──────┐┌──────┐┌──────┐┌──────┐ │
│  │ 12卷  ││ 5件   ││ ¥17K ││ 3过期 │ │  ← 统计卡片
│  └──────┘└──────┘└──────┘└──────┘ │
│                                    │
│  状态 [全部 ▼]  类型 [全部 ▼]  搜索│  ← 筛选栏 (简洁)
│                                    │
│  型号     数量   状态    到期       │  ← 表格, 可排序
│  Portra   5卷    🟢      -        │
│  E100     20张   🟢   2026-12    │
│  Tri-X    2卷    📸      -        │
│                                    │
└────────────────────────────────────┘
```

### 6.3 数据页面交互

```
Tab 切换: 下划线滑动过渡 (200ms)
筛选:    下拉选择器或标签式 (chip style)
搜索:     实时输入, debounce 300ms
排序:     点击列头, 可多列排序
分页:     无限滚动 or 点击 "加载更多"
返回:     左上角 ← 回到聊天, 保留筛选状态
```

## 7. 动效总览

| 场景 | 动效 | 时长 | 缓动 |
|------|------|------|------|
| 页面切换 | fade (路由切换) | 200ms | ease |
| 登录弹窗 | fade + scale | 300ms | ease-out |
| 侧栏展开 | slide from left | 250ms | ease-out |
| 消息出现 | fadeIn + slideUp | 200ms | ease-out |
| 流式 token | 打字机 | ~150ms/字 | linear |
| 工具指示 | fadeIn | 150ms | ease-out |
| 统计数字 | count-up | 600ms | ease-out |
| Tab 切换 | slide underline | 200ms | ease-in-out |
| Hover | 背景变亮 | 150ms | ease |
| 点击反馈 | scale(0.97) | 100ms | ease |
| Toast | slideDown + fadeOut | 300ms + 3s | ease |

## 8. 移动端专项

```
底部安全区: env(safe-area-inset-bottom)
键盘适配:   input 聚焦时, 页面自动上推, 不遮挡输入框
侧栏手势:  从屏幕左边缘右滑打开
消息操作:  long press 弹出操作菜单
点击区域:  所有交互元素 ≥44px
回退手势:  侧栏打开时, Android 返回键关闭侧栏而非退出页面
```

## 总结

```
交互:  像 ChatGPT/豆包一样聊天
布局:  全屏聊天, 侧栏隐藏/弹出, 消息居中
主题:  5 套可切换 (极简白/深空灰/暖阳米/暗房红/墨绿)
       每套支持 dark/light + 跟随系统
动效:  克制温和, 不做花哨动画
数据:  独立页面 /data, 保留聊天上下文
```
